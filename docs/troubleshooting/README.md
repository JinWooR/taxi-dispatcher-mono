# 🔧 Troubleshooting

개발 중 마주친 **문제 → 원인 → 해결** 과정을 기록합니다.

---

## 📝 작성 템플릿

**파일명**: `문제-주제.md`
- 예: `gradle-docker-crlf-error.md`, `port-mapping-conflict.md`

**템플릿**
```markdown
# [문제 제목]

## 증상
[어떤 오류가 났는가]

## 원인
[왜?]

## 해결
[어떻게 고쳤는가]

## 체크리스트
- [x] 원인 파악
- [x] 해결 방법 적용
- [x] 테스트 완료

## 최종 정책 (필요시)
→ `decisions/` 폴더에 등록
```
