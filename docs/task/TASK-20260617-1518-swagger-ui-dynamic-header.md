# 🚀 Swagger UI Docker Compose 동적 타이틀 설정 요청서

## 1. 개요 및 목적
* **기술 스택**: Docker Compose, Swagger UI 공식 이미지 (`swaggerapi/swagger-ui`)
* **목적**: 로컬에서 실행 중인 여러 개의 백엔드 API 서버(명세서)를 단일 Swagger UI 컨테이너에서 드롭다운 메뉴로 통합 관리하기 위함입니다.
* **핵심 요구사항**: 상단 드롭다운 메뉴에서 사용자가 다른 API를 선택(전환)할 때마다, **브라우저 탭의 타이틀(`<title>`)이 해당 API의 `name`에 맞춰 실시간으로 동적 변경**되어야 합니다.

---

## 2. 동적 타이틀화 구현 방식 (개념)
* Swagger UI는 페이지 새로고침 없이 명세 데이터만 비동기로 바꾸는 싱글 페이지 애플리케이션(SPA) 구조입니다.
* 공식 이미지에서 제공하는 고정형 환경 변수로는 화면 전환 시 타이틀을 바꿀 수 없으므로, 컨테이너 구동 시 `index.html` 내부에 **자바스크립트 DOM 이벤트 리스너를 주입**하는 방식을 사용합니다.
* 사용자가 상단 드롭다운(`select`) 항목을 바꿀 때 발생하는 `change` 이벤트를 감지하여, 현재 선택된 `<option>`의 텍스트 값을 브라우저의 `document.title`에 실시간으로 대입해 줍니다.

---

## 3. 작업 방법 (구현 가이드)
* 별도의 `Dockerfile` 빌드 과정 없이, `docker-compose.yml` 파일의 `command:` 속성을 활용해 인라인(Inline)으로 스크립트를 주입합니다.
* 컨테이너 진입점 스크립트가 실행되기 직전, `sed` 명령어를 통해 `index.html` 내 `window.ui = ui` 실행부 바로 뒤쪽에 커스텀 스크립트 코드를 삽입해야 합니다.
* 로컬 호스트 PC에서 구동 중인 백엔드 서버들과의 통신을 위해 `extra_hosts`에 `host.docker.internal` 매핑이 포함되어야 합니다.

## 🤖 Claude에게 보내는 최종 프롬프트 지시어

위 가이드라인을 바탕으로 아래 요구사항을 충족하는 완벽한 `docker-compose.yml` 코드를 작성해 줘.

1. **대상 API 서버 예시**:
    * 포트 `8081`: `🔐 인증/회원 서비스` (`/v3/api-docs`)
    * 포트 `8082`: `📦 상품/주문 서비스` (`/v3/api-docs`)
    * 포트 `8083`: `💳 결제/정산 서비스` (`/v3/api-docs`)
2. **주의 사항**:
    * `command:` 영역 내 `sed` 명령어 작성 시, 셸 스크립트 내부 문법과 Docker YAML 문법이 충돌하여 에러가 나지 않도록 싱글/더블 쿼테이션(`'`, `"`) 부호, 줄바꿈 문자(`\n`), 이스케이프 처리를 완벽하게 검증해서 한 번에 동작하는 실무 코드로 제공해 줄 것.
